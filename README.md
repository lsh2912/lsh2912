- 상세 역할 및 학습 성과

  - **이종 언어 모듈 연동:** C++ 기반의 MFC DLL을 C# WPF 환경에 연동하여 기존 모듈의 재사용성 확보
  - **로컬 DB 구축:** SQLite를 활용하여 분석 데이터를 로컬에 저장하고 조회하는 데이터 관리 기능 구현
